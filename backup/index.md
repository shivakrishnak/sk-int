# SK Interview

A condensed, interview-focused technical reference with deep Q&A for every concept. Complete knowledge per topic - zero to mastery - without needing other sources.

!!! info "Getting started"
Topics will appear in the navigation as they are added. See the [topic registry](https://github.com/hv-shiva/southstar/blob/main/spec/topics_registry.md) for the planned coverage map.

## How this is organised

Each topic lives in its own folder under `docs/` and is split into subtopic files of 3-5 keywords each. Every keyword entry follows the **Interview Mastery Dictionary v1.0** structure:

- TL;DR (25 words)
- The Problem This Solves
- Textbook Definition
- Understand It in 30 Seconds
- First Principles
- Mental Model / Analogy
- Gradual Depth - Five Levels (L1-L5)
- How It Works (with ASCII + Mermaid diagrams)
- End-to-End Flow (normal + failure + scale)
- Code Example (BAD before GOOD, production-grade)
- Quick Reference Card
- Mastery Checklist
- The Surprising Truth
- Comparison Table (when alternatives exist)
- Common Misconceptions (min 4)
- Failure Modes and Diagnosis (min 3, with real commands)
- Interview Deep-Dive (7-12 full Q&A by difficulty)
- Related Keywords

Every entry must pass eight Quality Constitution tests (Search Again, Feynman, Senior, Staff, Production Reality, Retention, Decision, Scale) and the final gate: _"Would an experienced engineer say 'Damn - this is genuinely excellent'?"_ Masterclass is the target.
