# AWS

Amazon Web Services - the dominant cloud platform. Covers core services
(EC2, S3, VPC, RDS, Lambda), messaging (SQS, SNS, EventBridge),
security (IAM, GuardDuty, Security Groups), observability (CloudWatch,
X-Ray), Infrastructure as Code (CloudFormation, CDK), Kubernetes (EKS),
the Well-Architected Framework, and multi-region architecture.
