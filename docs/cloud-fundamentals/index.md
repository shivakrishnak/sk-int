# Cloud Fundamentals

Cloud computing concepts, models, and architecture patterns that apply
across all providers. Covers IaaS/PaaS/SaaS models, virtual networking,
IAM, Infrastructure as Code, high availability, disaster recovery, cost
optimization, cloud-native architecture, security, and strategic decisions
about multi-cloud and migration.
