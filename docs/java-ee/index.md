# Java EE

Java Enterprise Edition (now Jakarta EE) - the standard platform for
building enterprise Java applications. Covers the full specification
stack: Servlets, CDI, EJB, JAX-RS, JTA, Bean Validation, JAAS,
application server deployment, and the strategic migration path to
Spring and MicroProfile.
